================================================================================
MY 3D AI OFFICE — ZERO-BUDGET DIGITAL STUDIO README
================================================================================

A browser-native 3D AI Office command center built with HTML, Tailwind CSS, and
Three.js—designed to run on a $0-overhead stack with persistent browser memory,
a numbered Brain Vault, automated daily syncs, and a linked storefront.

--------------------------------------------------------------------------------
LIVE WEBSITES
--------------------------------------------------------------------------------
* 3D AI Office Workspace : https://my-digital-office.pages.dev/
* Public Creator Shop    : https://my-digital-office.pages.dev/store.html

--------------------------------------------------------------------------------
REPOSITORY STRUCTURE & KEY FILES
--------------------------------------------------------------------------------
* index.html
  3D isometric AI Office (Three.js), Chief of Staff & specialist agents,
  agent inspector/customizer, command console (/setup, /new-agent, /teach,
  /tidy, /briefing), Guard approval modal, automatic login briefing, and
  persistent localStorage memory.

* store.html
  Public-facing digital storefront with editable shop name, bio, Gumroad URL,
  and profile photo, linked back to the 3D AI Office and Gumroad products.

* products.json
  Catalog of live digital products (name, URL, price, format, hook, target
  buyer, status) inspected during automated sync runs.

* brain-feed.json & brain-logs/daily-research.md
  Automated daily output generated by GitHub Actions containing Scout
  research ideas, marketing hooks, and product inspection results.

* .github/workflows/daily-office-sync.yml
  Scheduled GitHub Actions workflow (runs daily at 09:00 KST / 00:00 UTC or
  manually via "Run workflow") that updates brain-feed.json and commits logs
  back to the repository for Cloudflare Pages deployment.

--------------------------------------------------------------------------------
HOW TO USE YOUR 3D AI OFFICE
--------------------------------------------------------------------------------
1. Open https://my-digital-office.pages.dev/ in your browser.
2. Run "/setup" (or click the /setup button) to set your studio name, Chief of
   Staff name, and first zero-budget revenue stream.
3. Click "+ Spawn Agent" to add focused specialists ("one agent, one job")
   such as Product Builder, Copywriter, or Traffic Scout.
4. Assign tasks in plain words in the bottom command bar, save rules with
   "/teach <rule>", and keep your notes organized inside "Brain Vault".
5. Review your "Daily Briefing" when logging in (or via "/briefing") and
   accept strong ideas/audits straight into your Brain Vault.
6. Update "store.html" and "products.json" as you publish products on Gumroad
   or Payhip, then push to GitHub so Cloudflare Pages updates automatically.

--------------------------------------------------------------------------------
SAFETY & ZERO-BUDGET PRINCIPLES
--------------------------------------------------------------------------------
* $0 Overhead Stack: Built around free tiers (GitHub, Cloudflare Pages,
  Gumroad/Payhip) with no required paid subscriptions or paid API keys.
* Human-in-the-Loop Guard: Publishing, sending, or external changes stay
  gated behind explicit approval.
